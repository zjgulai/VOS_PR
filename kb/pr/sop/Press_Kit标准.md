# Press Kit 组件标准 SOP

> 版本：v1.0 | 日期：2026-08-13
> 依据：GetGoMedia Press Kit 指南 + Prowly Newsroom 建设标准 + InstantPress 记者下载行为数据

---

## 一、记者最常下载的 5 类资产（优先级排序）

| 排名 | 资产类型 | 下载率 |
|---|---|---|
| 1 | Logo（多格式）| 95% |
| 2 | 产品高清图 | 85% |
| 3 | CEO/发言人头像 | 75% |
| 4 | Fact Sheet | 65% |
| 5 | 产品视频/Demo | 55% |

→ **优先确保前 4 类随时可下载，更新产品图≥一季度一次**

## 二、Press Kit 7 大必备组件

### 1. 公司 Boilerplate（品牌标准描述）
- 长版（100 字）：用于 About Us 页面和新闻稿
- 短版（25 字）：用于媒体提及署名
- 禁止：形容词堆砌（world-class/revolutionary/amazing）
- 必须包含：成立时间、核心产品品类、市场规模或认证

### 2. Fact Sheet（事实页）
- 创始时间、总部、团队规模
- 核心产品线 + 旗舰型号
- 关键认证（FDA 510(k)/EWG/IBCLC 认证等）
- 关键市场数据（可引用第三方）
- 最近 12 个月重要里程碑

### 3. 高管/发言人简介
- 150 字：职位 + 关键资质 + 1 个具体成就
- 头像：专业照（≥1200px，白色或简洁背景，JPEG+PNG 两版）
- 禁止：LinkedIn 腔（passion for/thought leader/guru）

### 4. Logo 文件包
- 主 logo（彩色 + 白色 + 黑色）
- 格式：SVG + PNG（透明背景）+ EPS
- 尺寸：@1x / @2x / @3x
- 附带品牌使用规范（可用色/禁用变体）

### 5. 产品图像库
- 旗舰产品：最少 6 张（正面/侧面/使用场景/细节/包装/白底）
- 分辨率：≥3000px 宽（300 DPI）
- 格式：JPEG（出版用）+ PNG（网页用）
- 使用场景图（lifestyle shots）必须有真实妈妈，非 AI 生成

### 6. 最近新闻与奖项
- 最近 3 条新闻稿（全文 PDF）
- 已获媒体奖项和测评清单（带媒体 logo + 链接）
- 更新频率：每季度

### 7. 媒体联系信息
- PR 联系人姓名 + 邮箱 + 手机（随时回复，24 小时内）
- 备用联系人（PR Lead）
- 新闻室 URL：`momcozy.com/newsroom`（待建）

## 三、数字媒体室（/newsroom）建设要求

按 Prowly 标准，品牌新闻室需包含：

| 版块 | 内容 |
|---|---|
| 媒体资产库 | 所有 Press Kit 资产可点击即下载（无需注册） |
| 新闻稿归档 | 全文 + PDF，按日期倒序 |
| 品牌故事 | 创始故事 + 核心价值观（≤300 字） |
| 产品页 | 每款旗舰产品的专属页面（含技术参数） |
| 媒体报道 | 精选媒体报道 + 媒体 logo 墙 |
| 联系方式 | PR 专用邮箱，置顶显示 |

---

## 四、更新节奏

| 频率 | 更新内容 |
|---|---|
| 每次发布新品前 | 补充新产品图/数据/认证 |
| 每季度 | 全量检查所有链接是否有效 |
| 每次获奖 | 48 小时内更新奖项展示墙 |
| 每年 | 刷新团队头像和公司数据 |

---

## 五、媒体资产命名规范

```
[品牌]_[类型]_[规格]_[版本].[格式]

示例：
momcozy_logo_color_v2.svg
momcozy_m5_product_front_3000px.jpg
momcozy_ceo_headshot_2026.jpg
```

**铁律**：媒体工具包中所有图片须附使用授权说明（用于媒体报道可免费使用，不用于商业广告）。
