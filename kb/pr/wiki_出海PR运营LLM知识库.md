## 一、PR 基础认知（先破认知误区）

### 1.1 PR 的本质定义

PR（Public Relations）不是「发软文、投媒体」，而是**战略性沟通体系**：长期经营品牌与核心利益相关方的双向信任关系，管理声誉、塑造统一认知，实现品牌资产增值。

**核心底层逻辑**：
- 广告 = 付费买曝光，可控、短期、营销导向
- PR = 赢取第三方信任背书，不可控、长期、公信力导向
- 第三方媒体内容对购买决策的影响力是硬广的 **3 倍以上**（爱德曼信任度报告）

### 1.2 PR 七大全模块（多数人只做模块 1）

| # | 模块 | 核心场景 | Momcozy 现状 |
|---|------|---------|-------------|
| 1 | 媒介关系 Media Relations | 发稿、对接记者、评测、行业报道 | 正在做（工作日志） |
| 2 | 声誉与危机公关 Crisis PR | 安全投诉、集体维权、负面报道 | P0 预警系统覆盖 |
| 3 | 行业思想领导力 Thought Leadership | 白皮书、行业观点、展会 | ⚠️ 未覆盖 |
| 4 | 利益相关方沟通 Stakeholder PR | C端/B端/资本端/公共端 | ❌ 未覆盖 |
| 5 | 活动公关 Event PR | CES/IFA 展会、新品发布 | ❌ 未覆盖 |
| 6 | 内部公关 Internal PR | 海外团队口径对齐 | 不在范围 |
| 7 | 社媒公关 Digital PR | Reddit/LinkedIn 运营、UGC | ✅ 社媒 Intelligence 覆盖 |

### 1.3 三类媒体资产

1. **Owned Media 自有媒体**：官网、独立站、品牌官号（完全可控，PR 基础阵地）
2. **Paid Media 付费媒体**：付费软文、专栏赞助、KOL 商单（介于营销与 PR）
3. **Earned Media 赢得媒体**：媒体报道、第三方测评、编辑推荐（PR 的终极目标）

## 二、国内外 PR 差异（出海避坑核心）

| 维度 | 国内 PR | 海外 PR（Earned Media） |
|---|---|---|
| 逻辑 | 软文/付费版面保出稿 | 新闻价值 > 品牌需求，编辑决定是否报道 |
| 操作 | 群发通稿 | 一对一 Pitch，个性化角度 |
| 周期 | 快（周内） | 3-6 周，需提前布局 |
| 衡量 | 发了多少稿 | pitch 接受/拒绝率、媒体渗透率 |
| 禁忌 | — | 群发模板邮件会被编辑拉黑 |

**关键实操原则**：
- 海外媒体不可「买版面保出稿」，要从「编辑需要什么」出发，而非「我们想说什么」
- Pitch 必须个性化，同一编辑 pitch 频率过高会被拉黑（冷却期管理）
- 新闻价值 > 品牌需求：消费者报告给「Best Value」的影响力是自投广告的 3 倍

## 三、PR 实操方法论（来自知识库 18 篇）

### 3.1 6 种基础玩法

1. 新闻稿分发（PRNewswire/GlobeNewswire，SEO 价值有限）
2. 媒体 Pitch（一对一，基于编辑选题）
3. 产品 Seeding（寄样测评，成本低效果好）
4. 行业奖项申报（Babylist/The Bump/Parents 年度奖）
5. 专家背书（IBCLC/医生/KOL 认证）
6. 内容共创（UGC + 编辑合作）

### 3.2 媒体合作判断维度（工作日志实操标准）

评估一个媒体/写手是否值得合作，必查 5 项：
1. **网站流量**（月访问量，<1M 谨慎）
2. **受众地域**（美国/加拿大占比）
3. **内容方向匹配度**（skincare vs 旅游，方向不对直接放弃）
4. **报价合理性**（对比流量/曝光/是否挂链接）
5. **可追踪性**（是否可挂追踪链接、折扣码、是否标注赞助）

### 3.3 产品认证体系（工作日志调研）

按优先级：FDA 食品注册（强制）→ GFSI/SQF/BRCGS（沃尔玛强制）→ CLP 纯净标签 → USDA Organic → Non-GMO → GFCO 无麸质 → Kosher/Halal → Fair Trade → NSF → Vegan → ISO/IEC 17025 → FSSC 22000 → ConsumerLab → BSCG → Informed Choice
