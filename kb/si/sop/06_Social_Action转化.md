# SOP 06：Social Action 转化

> 版本：v1.0 | 日期：2026-08-13

---

## 一、Action 完整要素（缺一不可）

| 要素 | 定义 | 示例 |
|---|---|---|
| 来源洞察 ID | 触发此 Action 的 S1/S2/S3/S4 信号 | S3-2026-08-10-003 |
| 证据链 | 原始数据 URL + 时间 | reddit.com/r/... (2026-08-10) |
| 平台 | 在哪里执行 | TikTok / IG / YouTube |
| 内容方向 | 具体做什么（角度精确到一句话）| 发一条「30 分钟职场排奶路线图」Reel |
| 责任人角色 | 内容负责人 / Creator 合作 / 客服 | 内容负责人 |
| 截止时间 | 具体日期（不是「尽快」）| 2026-08-17 17:00 |
| 成功标准 | 可量化或可判断的验收条件 | 发布后 72h reach > 账号均值 |
| 状态 | 草稿待审 / 已审批 / 执行中 / 已完成 / 取消 | 草稿待审 |

---

## 二、审批流程

```
[AI 生成候选 Action 草稿（来源洞察 + 证据 + 建议内容方向）]
         ↓
[社媒 Analyst 审核：角度准确？执行可行？时机合适？]
         ↓ 批准 / 修改 / 拒绝
[责任人接收 Action，确认截止时间]
         ↓
[执行完成：上传结果（截图 URL + 实际指标）]
         ↓
[AI 系统接收结果，更新模型（洞察→Action→结果 映射）]
```

**铁律**：AI 生成的 Action 草稿必须经社媒负责人批准后才能对外发布。

---

## 三、优先级框架

| 优先级 | 触发条件 | 截止时间 |
|---|---|---|
| P0 立即行动 | 趋势在增长窗口（5K-20K 视频数）+ 品牌直接相关 | 48h 内发布 |
| P1 本周完成 | S1 高强度痛点（P0 评分≥12）/ S2 竞品爆款 | 7 天内 |
| P2 本月完成 | S4 Creator 建联 / S3 趋势晚期 / S2 竞品一般内容 | 30 天内 |
| P3 积累备用 | 好方向但暂无时机 | 无截止 |

---

## 四、月度复盘（每月一次）

| 问题 | 输出 |
|---|---|
| 执行了哪些 Action？成功率多少？ | Action 采纳率/成功率 |
| 哪类洞察触发的 Action 最有效？ | 洞察→Action 有效性排序 |
| 哪些 Action 被拒绝？为什么？ | AI 建议质量改进方向 |
| 趋势参与 Action 时效性（是否 <72h）？ | 时效 KPI |

## 五、Action Board 卡片格式

```
[Action 卡片]
来源：S3-TikTok-趋势 / S1-Reddit-痛点 / S2-竞品内容
平台：TikTok
内容方向：（精确到一句话）
责任人：内容负责人
截止：2026-08-17
成功标准：72h reach > 账号均值
证据：reddit.com/r/... (2026-08-10 10:32)
状态：草稿待审批
```
