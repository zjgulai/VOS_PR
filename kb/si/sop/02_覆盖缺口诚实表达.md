# SOP 02：覆盖缺口诚实表达

> 版本：v1.0 | 日期：2026-08-13
> 核心场景倒推：agent 抓到 Reddit 67 条、TikTok 30 条，但 Instagram 0 条（API 限制）、Facebook Groups 0 条（私密群无法抓取）。如果 agent 输出「Instagram 用户讨论量为 0」或「全平台监测数据」，就是重大错误——会误导业务决策。

---

## 一、为什么需要这个 SOP（未被满足的需求）

| 不做会发生什么 | 后果 |
|---|---|
| 把「抓不到」写成 0 | 业务误认为「Instagram 用户不讨论 Momcozy」，错过重要洞察 |
| 声称「全平台监测」但实际只覆盖 2/6 平台 | 损害周报可信度，业务无法信任 AI 输出 |
| agent 不标注缺口，analyst 无法判断数据完整性 | 无法评估洞察的置信度，错误决策风险上升 |

**设计原则**：v3 PRD 点名的最高翻车风险之一。诚实 > 看起来全面。

---

## 二、三类覆盖缺口

| 缺口类型 | 定义 | 示例 |
|---|---|---|
| **A 型：技术限制** | API 限制/平台不提供端点 | Instagram 非官方 API 不稳定，无法抓账号全量帖子 |
| **B 型：ToS 限制** | 平台条款禁止此类数据采集 | Facebook Groups 私密群无法抓取（Meta ToS） |
| **C 型：资源未配置** | 技术可行但尚未接入 | YouTube 采集器代码已写但 API key 未配置 |

---

## 三、标准化缺口标注模板

每份周报/洞察卡的「数据覆盖状态」部分必须包含：

```
## 本期数据覆盖状态

✅ 已覆盖
- Reddit（TikHub）：67 条，关键词：momcozy/breast pump/wearable pump
- TikTok（TikHub）：30 条，账号：eufy/elvie/willow（S2）+ hashtag（S3）

⚠️ 部分覆盖（数据受限）
- Instagram：已采集 @elvie/@willow 官方账号，但 hashtag 帖子无法全量（API 限制 A 型）
  → 影响：S2 竞品分析可能遗漏 IG 长尾内容；S1 IG 用户讨论未覆盖

❌ 未覆盖（需标注原因）
- Facebook Groups：目标公开群组 URL 待社媒团队提供（资源未配置 C 型）
  → 影响：S1 用户讨论的 Facebook Groups 渠道缺失；Reddit 不能代表 FB Groups
- YouTube（用户评论）：采集器已写但 API key 未配置（资源未配置 C 型）
  → 影响：S2/S4 YouTube Creator 内容未覆盖

本期洞察置信度：中等（覆盖 Reddit + TikTok，缺 IG/FB/YouTube）
```

---

## 四、禁忌表达 vs 正确表达

| 禁忌（会误导）| 正确（诚实表达）|
|---|---|
| Instagram 讨论量：0 | Instagram：本期未采集（A 型技术限制）|
| 全平台监测显示用户关注 X | Reddit + TikTok（2/6 平台）监测显示用户关注 X |
| 用户不在 Facebook 上讨论 | Facebook Groups 本期未覆盖（群组 URL 待配置）|
| 共采集 97 条全量数据 | 共采集 97 条（Reddit 67 + TikTok 30），其余 4 平台见覆盖缺口说明 |
| 趋势分析基于全平台 | 趋势分析基于 TikTok 数据，其他平台暂未覆盖 |

---

## 五、缺口优先级与修复路径

| 缺口 | 优先级 | 修复路径 |
|---|---|---|
| Facebook Groups（C 型） | P0 | 社媒团队提供群组 URL → 配置 Apify Actor |
| Instagram hashtag（A 型） | P1 | 评估 TikHub v3 端点可用性 / Apify 替代 |
| YouTube 用户评论（C 型） | P1 | 配置 API key，启用 youtube_collector |
| Facebook Pages 用户评论（C 型） | P2 | 配置已有 Apify actor |

---

## 六、执行检查点

每次生成周报/洞察前，agent 必须回答：
1. 本期采集了哪些平台？哪些没有？
2. 每个缺口是 A/B/C 哪类？影响哪些 S1-S4 洞察？
3. 是否有替代数据可以部分弥补（如 Reddit 可部分代表用户讨论，但不能代表 Instagram）？
4. 整体置信度评级：高（4+ 平台）/ 中（2-3 平台）/ 低（1 平台）

**铁律**：agent 不能在覆盖率「低」或「中」时声称「全平台」结论。必须标注「在已覆盖平台范围内」。
