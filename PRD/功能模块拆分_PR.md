# PR Intelligence 功能模块拆分

> 版本：v1.0 | 日期：2026-08-13
> 上游：批次 1 的 6 组 PR 业务问题 + 跨境 PR 文章（Earned Media 逻辑）
> 原则：每个模块必须回答「没有它会怎样」，且能映射到至少一个批次 1 的可验证指标

---

## 模块 0：共享底座（PR + SI 通用）

| 子模块 | 输入 | 处理 | 输出 | 衡量 |
|---|---|---|---|---|
| 采集调度 | 数据源矩阵（批次 2 T1/T2） | 定时/触发采集、幂等去重、游标恢复 | 原始数据入库 | 采集成功率 ≥95% |
| 证据链 | dwd_canonical_mention | 原始内容 → evidence 记录（引用/摘录/指标快照） | evidence_set | 每条洞察带 evidence_set_id |
| 覆盖率 | connector_registry 能力矩阵 | 字段缺口检测、缺失记 null | coverage_report | 覆盖率诚实表达 |
| 词典管理 | competitor_dictionary.json | 品牌/型号/handle/风险词版本化 | 词典 + 版本 | 词典版本可追溯 |
| Action 状态机 | 各洞察模块 | 候选 → 审核 → 执行 → 复盘 | Action Board | Action 采纳率、闭环时间 |

## 模块 1：品牌声誉健康度诊断

- **回答的问题**：本周 Momcozy 的声量与情感趋势如何？核心信息渗透率多少？
- **输入**：pr_articles + social_posts 的品牌提及 + 情感标注 + 核心话术命中
- **处理**：声量/情感聚合（按周/平台/市场）+ 核心信息渗透率计算（"Comfortable/Hands-Free/FDA Cleared/Science-backed" 在报道中的采用比例）
- **输出**：声量情感趋势图 + 核心信息渗透率 + 品牌健康度诊断
- **受众**：Global PR Lead
- **衡量**：声量环比、情感占比、核心信息渗透率趋势（对齐 AMEC「测态度改变，不测虚荣指标」）
- **没有它**：PR 团队只能靠碎片信息判断传播效果，无法证明 PR 活动是否有效触达核心话术

## 模块 2：竞品攻防与差异化卡位

- **回答的问题**：竞品本周有哪些新品/融资/测评/召回动态？哪里有 Momcozy 缺位的横评真空区？
- **输入**：竞品媒体 RSS（feed_collector）+ 竞品社媒内容 + 独立测评（Wirecutter/CR/BabyGearLab）
- **处理**：竞品事件提取（新品/融资/测评/召回/高管变动）+ 评测对比缺口识别（哪些横评没测 Momcozy）
- **输出**：竞品动态作战地图 + 评测对比缺口清单 + 差异化切入点建议
- **受众**：PR Analyst / Regional PR
- **衡量**：竞品事件捕获率、横评缺口命中数
- **没有它**：错过竞品负面窗口期（如 Willow 召回），也无法在竞品被夸赞时找到回击切入点

## 模块 3：媒体关系与精准 Pitch

- **回答的问题**：核心编辑最近关注什么选题？何时、以什么角度 Pitch 成功率最高？
- **输入**：编辑动态（媒体 RSS + 编辑社交）+ dim_media_contacts 历史 pitch 记录
- **处理**：选题预测（编辑近期发文/征询）+ Pitch 时机判断 + 冷却期管理（同一编辑 pitch 频率）
- **输出**：编辑档案卡（关注点/偏好/冷却期）+ Pitch 时机建议 + 角度建议
- **受众**：PR Analyst
- **衡量**：Pitch 回复率（目标 > 历史 1.5 倍）、冷却期违规次数
- **没有它**：只能群发通稿，海外编辑反感模板邮件，回复率低且可能被拉黑

## 模块 4：危机预警与风险防火墙

- **回答的问题**：有没有向主流媒体发酵的负面信号？监管（FDA/CPSC/召回）有没有相关动态？
- **输入**：监管 RSS（monitor.py 13 源）+ 风险词命中（competitor_dictionary risk_keywords）+ 负面提及
- **处理**：五维风险评分（S 权威度 ×35% + R 传播力 ×25% + B 品牌相关 ×20% + T 时效 ×10% + K 风险词 boost）+ Sev 分级（Sev0-Sev4）
- **输出**：P0/P1 实时预警（Sev4 15min / Sev3 60min）+ 风险评级 + 建议回应口径
- **受众**：Regional PR / Legal
- **衡量**：风险提前量（P0 <4h）、误报率（月度跟踪）
- **没有它**：下一个 KleanPal 诉讼仍然是「偶然发现」，丧失 24-72 小时黄金应对时间

## 模块 5：议题设定与内容策略

- **回答的问题**：哪些行业升温话题值得 Momcozy 发声？用什么叙事切入？
- **输入**：跨圈层媒体（科技/健康/生活方式）+ 行业趋势 + UGC/测评观点
- **处理**：升温话题识别 + 品牌叙事匹配（Earned Media 逻辑：新闻价值 > 品牌需求）
- **输出**：议题机会清单 + 可切入叙事角度（如「职场泵奶权」「产后心理健康」「FemTech」）
- **受众**：PR Lead / 品牌
- **衡量**：议题采纳率、高管署名文章/Op-ed 产出
- **没有它**：品牌停留在「泵奶器功能宣传」，无法进入「女性赋能」等高级叙事

## 模块 6：战略决策支持

- **回答的问题**：进入新市场前，当地媒体对品类态度如何？
- **输入**：目标市场媒体 + 品类相关报道 + 竞品当地表现
- **处理**：新市场舆情评估（品类态度 + 关键议题 + 竞品位置）
- **输出**：新市场「入场温度计」报告
- **受众**：管理层
- **衡量**：战略决策引用次数（非量化，定性跟踪）
- **没有它**：品牌全球化扩张凭感觉，缺乏基于舆情事实的入场依据
