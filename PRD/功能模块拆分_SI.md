# Social Media Intelligence 功能模块拆分

> 版本：v1.0 | 日期：2026-08-13
> 上游：批次 1 的 4 组社媒业务问题（S1-S4）+ VR/PRD 社媒需求原话
> 原则：每个模块必须回答「没有它会怎样」，且能映射到至少一个批次 1 的可验证指标

---

## 模块 0：共享底座

与 PR 共用（采集调度 / 证据链 / 覆盖率 / Action 状态机 / 词典管理），见 `功能模块拆分_PR.md` 模块 0。社媒独有的底座扩展：

| 子模块 | 说明 |
|---|---|
| Creator 关注池 | 由团队配置公开 Creator 账号，不从模型自动猜测账号 |
| 趋势快照 | 记录 Hashtag/BGM/模板的时间快照，无历史快照不输出增长率 |
| 商业披露检测 | #ad/#sponsored/#gifted/paid partnership 识别，合作建议必带披露检查 |

## S1 用户讨论与需求洞察

- **回答的问题**：用户最近讨论什么？最关注哪些问题？有哪些新需求、痛点、内容机会或风险？
- **输入**：Reddit + Facebook Groups（重点）+ Instagram/YouTube/TikTok 的品牌/品类/话题提及
- **处理**：话题聚类 + 需求/痛点/疑问标签 + 情感分类 + 热度上升检测
- **输出**：话题卡（含讨论量/作者数/上升趋势）+ 需求/痛点卡 + 风险信号
- **受众**：社媒内容负责人
- **衡量**：洞察被内容团队采用数、风险话题识别率（Sev3+ 中 >60% 被评价为有价值）
- **没有它**：靠人工刷 Reddit/TikTok，覆盖不全、不系统，说不清「为什么做这个内容」

## S2 竞品社媒营销动作监控

- **回答的问题**：竞品最近重点推广什么？哪些内容表现突出？对我们内容策略有什么启发？
- **输入**：竞品官方账号内容（TikTok/Instagram/YouTube）+ 互动指标 + Campaign 信号
- **处理**：竞品内容分类（Campaign/新品/节点/Creator 合作/UGC/促销）+ 高表现内容标记（超账号基线）+ 传播重点聚合
- **输出**：竞品内容流 + 高表现内容清单（主题/形式/传播角度/可能原因）+ Momcozy 可借鉴角度
- **受众**：竞品监控负责人
- **衡量**：竞品内容覆盖完整度（三平台 >85%）
- **没有它**：竞品重要 campaign 被遗漏，内容策略只能复制已有经验

## S3 社媒热点与内容趋势洞察

- **回答的问题**：哪些趋势升温？哪些与品牌相关？适合参与吗？从什么角度切入？
- **输入**：TikTok/Instagram/YouTube 热门 Hashtag/BGM/视频模板 + 趋势快照
- **处理**：趋势识别（声量/作者数/增速）+ 母婴垂类趋势匹配 + 品牌适配评分（相关度/可行性/风险/时间窗）
- **输出**：趋势机会卡（热度/代表内容/常见玩法/时间窗/是否参与/切入角度）
- **受众**：社媒内容负责人
- **衡量**：趋势参与时效（高热趋势识别后 72h 内发布）
- **没有它**：追已经凉的趋势，或被动刷算法推送，无法主动识别

## S4 重点 Creator 内容分析

- **回答的问题**：重点 Creator 最近关注/创作什么？哪些表现好？有没有合作机会？
- **输入**：Creator 关注池内容（视频为主）+ 评论 + 商业披露 + 指标快照
- **处理**：Creator 主题/形式时间线 + 方向变化检测（30 天 vs 90 天）+ 高表现内容识别 + 竞品合作信号
- **输出**：Creator 内容方向卡 + 方向变化提示 + 合作时机/品牌安全卡
- **受众**：KOL 合作负责人
- **衡量**：竞品×KOL 合作发现数（从 dim_competitor_kol_collabs 发现此前未知合作）
- **没有它**：Creator 只按粉丝数排序，错过优质 KOL 或重复接触已被竞品锁定的 KOL

## Action Engine（洞察转化）

- **回答的问题**：哪些话题值得回应？哪些趋势值得跟进？哪些内容形式可借鉴？哪些 Creator 值得合作？
- **输入**：S1-S4 四个模块的 Insight
- **处理**：规则 + LLM 生成候选 Action → 优先级/紧迫性/证据完整度评分 → 人工审批状态机
- **输出**：Social Action Board（待审核/进行中/已完成/复盘）
- **受众**：社媒团队 + 品牌负责人
- **衡量**：Action 采纳率（首月 ≥50%）、驳回率（持续下降）
- **没有它**：洞察停在报告里，无法落地为可跟踪的执行动作
