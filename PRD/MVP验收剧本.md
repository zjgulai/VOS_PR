# MVP 验收剧本

> 版本：v1.0 | 日期：2026-08-13
> 用途：验证「网站 + 关联 Agent」P0 交付是否可用
> 每条剧本含：前置条件 / 操作步骤 / 预期结果 / 失败判定

---

## 剧本 1：PR Analyst 端到端闭环

**目标**：PR Analyst 完成一次真实采集 → 查看证据 → 生成周报草稿 → 把一条机会转为待审核 Action。

**前置条件**：
- 监管源 + 媒体 RSS 至少 3 个源返回真实数据（批次 2 T1 已验证）
- 竞品词典已加载（competitor_dictionary.json）
- LLM（Kimi + DeepSeek）可用

**操作步骤**：
1. 运行采集命令，得到本周 pr_articles 数据
2. 在网站「媒体中心」看到本周竞品/品牌报道瀑布流
3. 点击一条报道，展开证据链（原文链接 + 采集时间 + 来源权威度）
4. 触发周报生成，得到 PR Intelligence Report 草稿
5. 把草稿里一条「机会」转为 Action，进入待审核状态

**预期结果**：
- 周报草稿含：执行摘要 + P0/P1 预警 + 媒体竞品动态 + 机会清单 + PR Actions
- 每条结论可回溯到原始来源 URL
- Action 默认 `pending`，不能直接变 `approved`

**失败判定**：周报出现无来源的结论 / Action 能跳过审批直接执行 / 数据缺口被写成 0。

## 剧本 2：社媒 Analyst 端到端闭环

**目标**：社媒 Analyst 看到 S1-S4 证据 → 生成社媒周报 → 把一条趋势转为待审核 Action。

**前置条件**：
- Reddit + TikTok 已出真实数据（当前已 LIVE）
- 竞品词典已加载

**操作步骤**：
1. 在「社媒洞察」页查看 S1 用户话题 / S2 竞品内容 / S4 Creator
2. 点击一条话题卡，展开证据（原文 + 样本量 + 置信度 + 覆盖范围）
3. 生成 Social Media Intelligence Report 草稿
4. 把一条趋势机会转成 Trend Action，进入待审核

**预期结果**：
- 周报含 S1-S4 四模块 + Social Actions
- 数据覆盖不完整时，标题写「已覆盖范围内」而非「全平台」
- Action 继承 insight_id + evidence_set_id，默认待审核

**失败判定**：把 Facebook Groups 无数据当成「用户没讨论」/ Action 无证据引用 / 把模型推断写成事实。

## 剧本 3：P0 预警注入测试

**目标**：验证 P0 风险预警链路真正可用。

**前置条件**：监管源采集器可运行（或手动注入测试数据）。

**操作步骤**：
1. 手动注入一条 ClassAction.org「Momcozy 类诉讼」数据（模拟）
2. 观察风险评分与 Sev 分级
3. 验证 P0 信号触发推送

**预期结果**：
- 该条被标记为 Sev4（≥85 分），触发 15 分钟确认流程
- 预警含：原文 + 风险评级 + 建议回应口径

**失败判定**：注入后无预警 / Sev 分级错误 / 预警无原文链接。

## 剧本 4：覆盖率诚实表达

**目标**：验证「数据缺口可见」这一核心差异化。

**前置条件**：至少一个平台连接器不可用（如 Instagram）。

**操作步骤**：
1. 查看跨平台总览
2. 展开覆盖状态横幅

**预期结果**：
- 页面显示「Instagram 无有效数据」的 coverage gap，而非 0
- 指标卡显示「可比范围」

**失败判定**：缺失平台被静默隐藏 / 缺失值被当成 0 / 汇总写「全平台总量」。

---

## 验收通过标准（四条剧本全部通过）

- 至少一个真实获准连接器 + 一个离线 fixture 通过同一套 CanonicalMention 测试
- 所有报告数字可追溯到 DWS 查询和 evidence_set
- 平台缺口、字段缺失、限速、删除、模型失败都有可见状态
- Action 有人工审核、执行状态、复盘字段
- 不存在自动对外发帖 / 自动联系记者 / 自动联系 Creator
