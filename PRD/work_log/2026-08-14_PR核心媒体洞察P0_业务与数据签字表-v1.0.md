| 状态 | 含义 | 实施影响 |

## 8. Gate 0 通过判断

Gate 0 不要求 48 位编辑全部核验成功，但每位都必须有明确状态和责任角色。以下条件全部满足后，才允许真实采集和正式 UAT：

- P0 范围、时间窗口、输出和 P1 排除项已签字。
- 11 家媒体均有 verified US/en edition 或明确 `blocked`。
- 每一个真实请求的 source 均为 `approved`，且可存字段、保留期和删除流程已确认。
- P0 SKU、竞品、别名和风险相关性词典已签字。
- Brief reviewer、Media Risk reviewer、Action owner 和关系记录维护角色已确认。
- 第 0 周 baseline 方法和两轮 UAT 评审时间已确认。
- 硬门槛已接受，候选门槛已签字或有明确的 baseline 后决策规则。
