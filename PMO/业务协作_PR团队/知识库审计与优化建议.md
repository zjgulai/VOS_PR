# Momcozy PR 知识库审计与优化建议

> 版本：v1.1 | 审计日期：2026-08-14
> 审计范围：`kb/pr/knowledge-system/`（claims/sources/concepts/acceptance）+ `kb/pr/sop/`（6个SOP）+ `agent_system_prompt.md` + 业务输入 Excel（`momcozy pr 媒体关系全年规划表.xlsx`）
> 口吻：以推荐优化为主，非全盘否定；标注影响程度和建议优先级。

---

## 一、总体评价

知识库整体质量**高于行业平均水平**：交叉验证体系（L1/L2）、claims 可追溯、SOP 结构规范、合规框架（FDA/FTC/CPSC）完整。以下建议均属**可选优化**，不影响系统当前可用性，但落地后能显著提升 Agent 的决策精准度和业务对齐度。

---

## 二、发现的矛盾点和值得关注的结构问题

### 2.1 媒体分级标准：知识库 vs 业务输入存在命名差异

**现状**：
- 知识库 `agent_system_prompt.md` 中的媒体 ROI 过滤规则：「月流量 <100 万且报价 >$2,000 → 不推荐」
- 业务输入 Excel `1-1媒体分级标准` Sheet：Tier 3 定义为 `<1M UV`，直接对应「流量低」，B级媒体
- **潜在矛盾**：知识库 claims 中未明确 Tier 3 媒体的操作建议（维护/开发/测试），但业务 Excel 中 Tier 3 + B 级的操作是「高频触达：批量化/自动化邮件流」，与 SOP 中「pitch 必须 1:1 个性化」存在**表面张力**

**推荐优化**：
在 `claims.yml` 中补充一条 `CLM-MEDIA-TIER-001`，明确区分「B/C 级媒体的高频触达」是指新闻稿群发（非 Pitch 个性化），两者不矛盾但需在 Agent 决策时区分场景。优先级 **P1**。

---

### 2.2 Pitch 跟进规则：数据依据的时效性风险

**现状**：
- SOP `个性化Pitch模板.md` 引用的是 **Muck Rack 2025** 数据（「1 次跟进最理想」）
- 业务 Excel `资源库管理规则` 的 SOP 中明确「发送后 3 工作日内补全台账」，但未提跟进次数限制
- **潜在矛盾**：业务 SOP 关注的是台账录入，知识库 SOP 关注的是跟进规范，两者在「跟进」维度未对齐

**推荐优化**：
将业务 `资源库管理规则` 中的台账流程（6步SOP）补充到 `kb/pr/sop/` 下，新建 `媒体台账管理SOP.md`，与 Pitch 模板 SOP 形成闭环。优先级 **P1**。

---

### 2.3 Agent System Prompt 中品牌信息占位符未填写

**现状**：
- `agent_system_prompt.md` 第二节「品牌核心信息」全部是 `{{ }}` 占位符，包括核心产品线、话术、禁用表述、专家背书
- 业务 Excel `吸奶器核心媒体池` 和 `pitch策略细化` 已包含丰富的角色定位、话术方向和专家信息
- **实际影响**：Agent 在执行 Pitch 起草、机会识别等任务时，品牌信息模块为空，输出质量大幅受限

**推荐优化**：
这是**最高优先级的可执行优化**（P0）。业务确认表填写完成后，立即将以下信息注入 System Prompt：
1. 核心产品线（M5/M9/S12 Pro/V1 Pro/KleanPal 等）
2. 6类媒体角色定位话术（来自 `pitch策略细化` Sheet）
3. 禁用表述（来自 FDA/FTC 合规章节）
4. 可对外背书的专家名单

---

### 2.4 媒体关系操作策略：知识库 vs 业务输入有重复但不一致

**现状**：
- 知识库 `claims.yml` 中有 CLM-COMP 系列（竞品 PR 策略），但未涵盖业务 Excel 中定义的「6类媒体角色」框架
- 业务 Excel `pitch策略细化` 定义的 6 类媒体（权威新闻/母婴头部/科技/时尚/女性健康/商业财经）是**业务自有方法论**，知识库中没有对应 concept
- **潜在盲区**：Agent 在生成 Pitch 建议时，缺少这个媒体分类框架，容易把所有媒体用同一角度对待

**推荐优化**：
在 `concepts.yml` 新增概念 `CONCEPT-MEDIA-ROLE-6TYPE`，将 6 类媒体角色定位纳入知识图谱。同时在 `claims.yml` 补充 `CLM-MEDIA-ROLE-001`，将各类媒体的 Pitch 角度作为 operational-rule 固化。优先级 **P1**。

---

### 2.5 SEO/GEO 榜单追踪：知识库有理论，缺少具体缺席数据

**现状**：
- 知识库 `claims.yml` 有 CLM-AI 系列（GEO/AI 引用策略）和 CLM-COMP-004（Wirecutter 缺席）
- 但业务 Excel `1-3高权重SEO GEO Listicle` 列出了 23 条具体榜单，其中 **12 条 Momcozy 未入选**，包括 Wirecutter（主榜）、The Strategist、The Independent 等
- **潜在盲区**：知识库层面只有「Wirecutter 未入选」一条具体数据，缺少系统性榜单缺席清单，Agent 无法识别完整的 GEO 覆盖缺口

**推荐优化**：
将 23 条榜单追踪数据作为 `CLM-GEO-LISTICLE-001` 系列 claims 补充，标注每条榜单的入选状态和对应编辑。这是 GEO 策略落地的数据基础。优先级 **P0**。

---

### 2.6 下半年新品日历未在知识库中体现

**现状**：
- 业务 Excel 有完整的 2026 H2 新品日历（19 条，覆盖 7-12 月），涵盖吸奶器/喂养电器/婴幼儿/家纺/服纺/家居/护肤 7 条品线
- 知识库和 Agent System Prompt 中无任何「新品发布节奏」相关配置
- **实际影响**：Agent 生成的 PR 机会建议和 Pitch 时机建议，无法结合产品上市节奏，容易建议「错峰」的媒体动作

**推荐优化**：
在 `agent_system_prompt.md` 的品牌信息区块新增「2.5 新品上市日历」章节，注入 H2 产品线节奏。对于每个新品，Pre-launch seeding 应提前 6-8 周触发（结合 CLM-MOM-001 的时机建议）。优先级 **P0**。

---

### 2.7 媒体联系人库：知识库有方法论，但无法驱动具体动作

**现状**：
- 知识库定义了 Pitch 的「1:1 邮件」原则，但 Agent System Prompt 中没有编辑姓名、联系方式数据
- 业务 Excel `吸奶器核心媒体池` 有 48 位核心编辑（含 LinkedIn）
- `1-2核心媒体Core Media List` 有 242 位编辑（含职位、合作形式、负责人）
- **实际影响**：Agent 起草 Pitch 时只能生成通用模板，无法「第一句话呼应编辑近期文章」（SOP 要求），因为不知道编辑是谁

**推荐优化**：
建议将「核心媒体编辑库」作为 Agent 的 retrieval 数据源（而非写死在 prompt），在 Pitch 生成时动态检索对应编辑信息。这是知识库向「可执行 Agent」演进的关键一步。优先级 **P1**。

---

### 2.8 合规风险：「hospital-grade」描述问题未在话术规范中体现

**现状**：
- `claims.yml` CLM-REG-001 明确指出：FDA 不认可「hospital-grade pump」标签
- 但 `agent_system_prompt.md` 的「禁用表述」占位符为空，合规红线未注入
- **潜在风险**：Agent 生成 Pitch 草稿或媒体沟通内容时，可能无意中使用「hospital-grade」等未获 FDA 认可的表述

**推荐优化**：
将 CLM-REG-001/CLM-REG-002 的合规红线直接写入 System Prompt 「2.3 禁用表述」章节，不依赖 claims 引用，确保每次输出前都检查。优先级 **P0**。

## 四、不建议改动的内容（已是最佳实践）

以下内容经审计质量良好，**不建议改动**：

- **交叉验证体系**（L1/L2 evidenceGrade）：严谨、可追溯，是知识库的核心竞争力
- **Pitch 5原则的数据引用**（Muck Rack 2025）：数据权威，定量依据充分
- **危机响应 Sev 分级**（15/60 分钟时限）：行业最佳实践，与 CPSC/ACCC 框架一致
- **GEO/AI 可见性理论部分**（CLM-AI-001~005）：前沿且有交叉验证，保持即可
- **FDA/FTC/CPSC 合规框架**：第一方权威来源，不做主观修改
