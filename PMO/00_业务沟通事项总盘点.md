# 业务沟通事项总盘点

> 版本：v1.0 | 日期：2026-08-13
> 用途：PMO 目录的索引与主表。所有需要业务团队协作的事项统一在此登记，明细在各阶段子文件夹的 Excel 中。

---

## 一、目录结构说明

```
PMO/
├── 00_业务沟通事项总盘点.md          ← 本文件（主表 + 索引）
├── 01_阶段一_产品设计与数据契约/       ← 阶段性成果总结
├── 02_阶段二_数据采集落地/            ← 阶段性成果总结
├── 业务协作_社媒团队/
│   └── 社媒团队协作表.xlsx            ← 4 sheets（发给社媒团队）
└── 业务协作_PR团队/
    └── PR团队协作表.xlsx             ← 3 sheets（发给 PR 团队）
```

**Excel 使用约定（引导式，AI 先给答案，业务只做确认）**：
- **白色列 = AI 预填**：参考答案 + 选择原因 + 优先级（P0/P1/P2），业务无需从零想
- **黄色「业务确认」列 = 业务填写**：只需填「确认 / 修改 / 删除」，或在下方的空行新增
- **团队分开**：社媒团队只填社媒表（Facebook Groups / KOL / 竞品账号 / 周报接收人），PR 团队只填 PR 表（核心媒体 / 周报接收人 / 专家样机库）

## 三、优先级说明

- **P0（阻塞当前推进）**：#1 Facebook Groups 群组、#3 周报接收人、#5 部署服务器、#7 团队规模
- **P1（影响完整性）**：#2 竞品账号复核、#4 KOL 关注池、#6 工具调研
- **P2（影响精度，不阻塞）**：#8 型号确认、#9 别名映射、#10 次要品牌账号

**建议沟通节奏**：P0 项在本周内由业务负责人直接填写 Excel 并回传；P1 项在下一次社媒会议/KOL 会议上一并对齐。
