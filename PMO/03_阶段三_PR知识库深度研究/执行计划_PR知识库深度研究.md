# PR 知识库深度研究执行计划

> 版本：v1.0 | 日期：2026-08-13
> 背景：现有知识库（16 信源 / 10 主张 / 12 概念 / 2 SOP）偏向通用 PR 方法论，缺乏**出海 DTC 成功框架、竞品 PR 策略、IBCLC 专业生态、AI 时代 PR 新策略、PR 效果测量**等深度内容。
> 目标：用高质量、干净、行业成功框架的信源夯实每个知识层，引导 PR 团队建立可用的内容知识库。

## 二、7 个研究包（按优先级）

---

### 研究包 1：出海 DTC PR 成功框架 【P0，最高优先】

**目标**：找到与 Momcozy 类似的中国出海 DTC 品牌（Anker、DJI、Papier、ŌURA）PR 打法，提取可复用的成功框架。

**检索方向（具体 query）**：
- `Anker brand PR strategy earned media US market DTC`
- `DJI cross-border brand PR United States media coverage`
- `Chinese DTC brand PR playbook US market trust building`
- `cross-border DTC brand US media relations case study`
- `FemTech DTC brand PR breakthrough Elvie Willow media coverage`
- `Chinese brand earned media Western market credibility gap strategy`

**预期产出**：
- 3-5 条 claims（中国品牌信任度障碍 / 出海 PR 第一步选题 / DTC PR ROI 数据）
- 3-5 个新信源
- 1 个概念（China-to-West Brand Credibility Gap）
- 可能新 SOP：出海品牌 Pitch 特定角度

---

### 研究包 2：母婴品类专业生态 【P0，最高优先】

**目标**：深入母婴/母乳/可穿戴泵的专业生态——IBCLC 认证机构、AAP/AAFP 推荐、Baby Product 奖项评审机制、母婴媒体测评体系。

**检索方向（具体 query）**：
- `IBCLC lactation consultant endorsement brand partnership value`
- `AAP AAFP breastfeeding recommendations breast pump guidelines`
- `Babylist award methodology selection criteria best baby products`
- `The Bump Parents magazine award criteria baby products`
- `Consumer Reports breast pump testing methodology`
- `Wirecutter breast pump review editorial process`
- `breastfeeding advocacy organizations ILCA ABM maternal health`

**预期产出**：
- 5-8 条 claims（IBCLC 背书价值/AAP 推荐/奖项权威度/Wirecutter 测评标准）
- 5-8 个新信源（AAP、ILCA、各媒体奖项官方页面）
- 3 个概念（Award Program / IBCLC Endorsement / Editorial Review）

---

### 研究包 3：竞品 PR 策略深度 【P0，最高优先】

**目标**：拆解 Elvie/Willow/Medela/eufy 是如何进入 Wirecutter、Consumer Reports、Babylist 等核心媒体的，提取可复用 PR 打法。

**检索方向（具体 query）**：
- `Elvie breast pump PR strategy Wirecutter media coverage how`
- `Willow breast pump earned media Consumer Reports Babylist`
- `Medela PR strategy brand narrative 2024 2025`
- `eufy baby brand US PR media coverage strategy`
- `FemTech brand media relations maternal health press coverage`
- `wearable breast pump brand PR crisis recall communication`

**预期产出**：
- 5 条 claims（竞品媒体突破路径 / 竞品奖项策略 / 竞品危机案例）
- 竞品 PR 策略概述补充到 claims.yml
- 可能新 SOP：竞品监测 → Pitch 时机判断

---

### 研究包 4：AI 时代 PR 新策略 【P1，重要】

**目标**：深度研究 GEO（Generative Engine Optimization）、Reddit/Quora 作为 PR 新渠道、Thought Leadership 在 AI 搜索中的权重，以及 AI 时代 Earned Media 的新标准。

**检索方向（具体 query）**：
- `Generative Engine Optimization GEO PR strategy 2025 2026`
- `Reddit Quora PR strategy brand mentions earned media`
- `thought leadership executive PR AI search citation visibility`
- `entity recognition brand building AI Google Knowledge Graph`
- `ChatGPT Perplexity brand citation AI search PR strategy`
- `AI search visibility earned media authority signals 2026`
- `PRSA AI era earned media measurement citation rate`

**预期产出**：
- 5-8 条 claims（AI 搜索引用 / Reddit 权重 / GEO 方法论）
- 4-5 个新信源（GEO 研究报告、Reddit PR 案例）
- 3 个新概念（GEO、Entity Recognition、AI Citation）
- 1 个新 SOP：AI 时代 Earned Media 优化

---

### 研究包 5：PR 合规深度 【P1，重要】

**目标**：深挖 FDA 510(k) 对吸奶器的具体分类与要求、FTC 母婴产品健康声明特定规则、CPSC 吸奶器/婴儿喂养电器的历史召回统计，与 Momcozy 现有 PR 文案对齐。

**检索方向（具体 query）**：
- `FDA 510k breast pump Class II medical device requirements`
- `FTC health claims baby products endorsement guidelines specific`
- `CPSC breast pump baby product recall statistics history`
- `FTC health claims maternal products nursing breastfeeding compliance`
- `breast pump FDA regulation marketing claims allowed prohibited`
- `CPSC infant product safety recall trends 2023 2024 2025`

**预期产出**：
- 5-8 条 claims（FDA 分类 / FTC 健康声明规则 / CPSC 召回统计）
- 5 个新信源（FDA 官方 / FTC 官方 / CPSC 统计数据）
- 1-2 个新概念（Health Claim / FDA Class II Device）
- claims.yml 中 FTC 合规条目深化

**预期产出**：
- 8-10 条 claims（SOV 计算 / 信息渗透率 / PR ROI 框架 / AMEC 实践）
- 6-8 个新信源（AMEC 官方 / PRSA / Cision 方法论）
- 5 个新概念（SOV / Message Penetration / Media Tier / PR ROI / Outcome Measurement）

## 五、执行说明

1. 每个研究包用**6-8 路并行搜索**完成，每路产出 1-3 个高质量信源
2. 信源入 `sources.yml`，主张入 `claims.yml`，概念入 `concepts.yml`，SOP 入 `kb/pr/sop/`
3. 原始文章存入 `kb/pr/out_search/`（命名：`研究包编号_主题.md`）
4. 每个研究包完成后更新 `wiki_出海PR运营LLM知识库.md` 对应章节
