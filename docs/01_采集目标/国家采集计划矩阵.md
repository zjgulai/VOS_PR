# 国家采集计划矩阵

## 1. 目标

把“国家 × 品线 × 平台 × 批次”转换为可执行、可追踪的计划矩阵。

## 2. 矩阵字段

| 字段 | 说明 |
|---|---|
| country_code | 国家编码 |
| wave | 波次（Wave1/Wave2/Wave3） |
| product_line_code | 品线 |
| platform_code | 平台 |
| priority_level | P1/P2/P3 |
| collection_mode | auto/semi/manual |
| owner | 负责人 |
| planned_start / planned_end | 计划时间 |
| actual_status | pending/running/success/failed/login_wall |
| blocker | 阻塞原因 |
| next_action | 下一步动作 |

## 3. 执行节奏

- Wave1：跑通端到端流程，验证模板和 QA
- Wave2：扩重点国家并补强评论树
- Wave3：扩长尾国家并优化效率

## 4. 当前管理建议

- 所有国家任务统一进入任务台账（后台看板）
- 登录墙问题单独建队列，不与普通失败混合
- 批次复盘按“成功率、回补率、平均时长”三指标评估
