# 采集口径与字段规范

## 1. 目标定义

本项目采集目标是围绕母婴品线（当前以吸奶器为试点），构建可持续的跨国家 VOC 数据资产，支持：

- 国家优先级判断
- 品线机会识别
- 竞品/痛点/场景洞察
- 与业务指标联动分析

## 2. 采集对象口径

- 内容对象：帖子、评论、视频、视频评论
- 平台范围：L1-L5 分层来源（权威、社区、电商、内容平台、趋势类）
- 时间范围：默认最近 365 天（特殊国家可扩展）
- 地域范围：按国家目录推进，以批次执行表为准

## 3. 核心字段（最小可用集）

| 字段 | 说明 |
|---|---|
| country_code | 国家编码 |
| platform_code | 平台编码 |
| source_content_id | 源内容 ID |
| content_type_std | 标准化内容类型（post/comment/video/video_comment） |
| title_std / body_std | 标题与正文 |
| publish_time | 发布时间 |
| url_raw | 原始 URL |
| like_cnt / reply_cnt / view_cnt | 互动指标 |
| lang_code | 语言编码 |
| product_line_code | 品线编码 |
| priority_level | P1/P2/P3 |
| tag_type / tag_value | 情感、主题、场景标签 |
| entity_type / entity_value | 品牌、SKU、功能点等实体提及 |

## 4. 数据质量口径

- 必须保留原始 URL 与抓取时间
- 允许字段缺失，但不允许伪造文本
- 登录墙场景必须记录页面状态与失败原因
- Markdown 渲染文本不得污染 Excel 单元格
