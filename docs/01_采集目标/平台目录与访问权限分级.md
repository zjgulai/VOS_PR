# 平台目录与访问权限分级

## 1. 分级标准

按可访问性与自动化难度，将平台划分为三层：

- A 类（公开可抓取）：公开网页、公开论坛、公开资讯页
- B 类（半受限）：需要展开、分页、动态渲染、轻量防护
- C 类（强受限）：登录墙、评论树隐藏、风控校验、App 才可见

## 2. 平台级风险示例

| 平台类型 | 典型问题 | 分级 |
|---|---|---|
| Amazon 详情页评论 | 评论树不直出、地区站点结构差异 | B/C |
| Shopee / Lazada | 登录墙、频控、反自动化 | C |
| TikTok / Facebook 深链 | 登录态评论、滚动加载 | C |
| 论坛站点 | 分页 + JS 渲染 + 反爬策略 | B |
| 权威媒体/资讯站 | 结构稳定，通常公开可读 | A |

## 3. 权限策略

- A 类：默认自动化采集
- B 类：自动化优先 + 失败回补
- C 类：进入合规登录流程，人工/半自动补抓并留痕

## 4. 输出要求

每个平台都必须维护：

- `access_mode`（public/login/manual）
- `auth_required`（是/否）
- `rate_limit_note`（频控说明）
- `fallback_strategy`（失败后兜底方案）
