# 后台管理看板设计规范

## 1. 用户与目标

- 用户：采集运营、数据工程、项目经理
- 目标：管理采集任务、处理异常、提升执行效率

## 2. 核心模块

- 任务队列：国家/平台/状态/负责人/批次
- 登录墙队列：需人工处理的 URL 与 SOP
- 批次管理：Wave 进度、成功率、失败率
- 质量面板：QA 状态、污染扫描、字段异常
- 执行日志：脚本耗时、错误堆栈、输出行数

## 3. 必要功能

- 状态筛选与搜索
- 批量重试失败任务
- 手工标记与处理备注
- 任务详情页查看输入输出
- 一键导出任务报告

## 4. 治理要求

- 所有状态变更必须有时间戳和操作人
- 人工处理必须保留处理备注
- 登录墙任务必须可追溯到原始 URL
