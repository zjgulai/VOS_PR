# 前台看板设计规范

## 1. 用户与目标

- 用户：业务负责人、分析师、市场同学
- 目标：快速查看国家/品线 VOC 趋势与可行动洞察

## 2. 核心页面

- 首页：项目概览（国家覆盖、采集状态、数据更新时间）
- 数据浏览：国家 × 品线 × 平台三维筛选
- 竞品分析：品牌提及与声量趋势
- 问题雷达：负向主题聚类与变化趋势

## 3. 交互要求

- 默认按国家 + 品线过滤
- 所有图表支持时间范围切换
- 支持导出筛选结果（CSV）
- 支持跳转到对应证据 URL

## 4. 指标口径

- 声量：内容条数
- 负向率：negative_cnt / content_cnt
- 互动率：互动总量 / 内容条数
- 竞品份额：品牌提及数占比
