# 平台维度定义表

> 版本：v1.0 | 日期：2026-08-12  
> 数据来源：三份 PR 方案文档萃取 + 二次审计（结合项目现有采集能力与仓库列表）  
> 覆盖范围：VOC 数据产品（用户评论采集）+ PR Intelligence（媒体监测）两条产品线

## 一、分类体系说明

### 1.1 平台大类（`platform_category`）

| 代码 | 含义 |
|------|------|
| `EC_REVIEW` | 电商评论平台（Amazon、Shopee 等） |
| `SOCIAL` | 社交媒体（TikTok、Instagram、Twitter/X 等） |
| `COMMUNITY` | 社区论坛（Reddit、BabyCenter 等垂直社区） |
| `MEDIA_EDITORIAL` | 编辑型媒体（Forbes、Wirecutter、Parents 等） |
| `MEDIA_REVIEW` | 测评型媒体（Consumer Reports、BabyGearLab 等） |
| `REGULATORY` | 监管与政策源（FDA、CPSC、Health Canada 等） |
| `DTC_REVIEW` | DTC 品牌官网评价（TrustPilot、Okendo 等） |
| `VIDEO` | 视频平台（YouTube、TikTok 内容侧） |
| `SEARCH_TREND` | 搜索趋势（Google Trends 等） |
| `DATA_API` | 数据聚合 API（GDELT、NewsAPI、Meltwater 等） |

### 1.2 访问分级（`access_tier`，对应现有采集方法论）

| 等级 | 含义 | 采集策略 |
|------|------|----------|
| `A` | 公开可抓取，结构稳定 | 自动化采集 |
| `B` | 半受限，需分页/JS渲染/轻量防护 | 自动化优先 + 失败回补 |
| `C` | 强受限，登录墙/频控/强反爬 | 登录态 / 半自动 / API |
| `API` | 官方 API，需申请/付费 | 按配额调用 |
| `PAID` | 付费数据服务，需采购合同 | 采购后对接 |

### 1.3 产品线关联（`product_line`）

| 代码 | 含义 |
|------|------|
| `VOC` | 仅用于 VOC 用户评论采集 |
| `PR` | 仅用于 PR Intelligence 媒体监测 |
| `BOTH` | 两条产品线均有价值 |

### 1.4 信息源质量基础权重（`base_weight`，0–100）

参见重构方案第十二章权重体系，此处简化为 5 档：

| 分档 | 范围 | 含义 |
|------|------|------|
| S | 80–100 | 战略级，高权威、高可信、高相关 |
| A | 65–79 | 核心级，主流媒体或强信号平台 |
| B | 50–64 | 补充级，有价值但噪声较高 |
| C | 35–49 | 观察级，碎片化或娱乐属性强 |
| D | 0–34 | 弱信号，主要用于趋势发现 |

## 三、能力边界总结（当前 vs 目标）

### 3.1 VOC 数据产品采集现状

| 平台分级 | 当前覆盖 | 主要缺口 | 修复路径 |
|----------|----------|----------|----------|
| A类（公开）| 🟡 部分（TrustPilot/Okendo/静态页）| DTC品牌官网不统一 | firecrawl批量 + autoscraper自学习 |
| B类（半受限）| 🟡 部分（Amazon httpx，易被封）| YouTube评论完全缺失 | crawlee+Camoufox替换Amazon；Agent-Reach修复YouTube |
| C类（强受限）| 🔴 极弱（Shopee全返login_wall）| Shopee/Reddit/TikTok/Twitter全空白 | crawlee SessionPool + Agent-Reach路由层 |

### 3.2 PR Intelligence 采集缺口

| 类别 | 缺口严重度 | 最高优先修复 |
|------|-----------|-------------|
| 监管源（CPSC/FDA/FTC/Health Canada）| 🔴 P0——已有活跃风险信号未监测 | 立即接入 RSS/公告页变更监测 |
| 核心媒体榜单监测（What to Expect/Reviewed/GH US）| 🔴 P0——三个高优先缺口 | 用 firecrawl 监测页面变更 |
| 编辑动态追踪（Twitter/LinkedIn）| 🟠 P1 | Agent-Reach（twitter-cli + linkedin-mcp）|
| 竞品监测（Willow/Eufy/Medela等）| 🟠 P1 | 复用上述采集能力，增加竞品关键词 |
| AI Citations追踪（ChatGPT/Gemini）| 🟡 P2 | Signal AI 或自建查询 |

### 3.3 新增平台纳入优先级

| 优先级 | 平台 | 理由 |
|--------|------|------|
| P0 立即 | CPSC、FDA、Health Canada、FTC | 监管风险已具象化（KleanPal诉讼、参议院问询） |
