# 工作流自动化设计

## 1. 目标

在不重写现有 `execute_*.py` 的前提下，引入统一调度层，实现：

- 任务注册
- 依赖控制
- 状态管理
- 日志追踪
- 失败回补

## 2. 建议组件

```text
workflow_engine.py   # 调度核心
task_registry.py     # 任务元数据
state_store.py       # SQLite 状态存储
batch_runner.py      # 批量执行入口
login_wall_handler.py# 登录墙处理器
```

## 3. 状态模型

- `pending`
- `running`
- `success`
- `failed`
- `login_wall`
- `manual_review`
- `skipped`

## 4. 执行规则

- 支持任务依赖（上游成功才执行）
- 支持失败重试（次数可配置）
- 登录墙任务自动转人工队列
- 每次执行都写入任务日志

## 5. 输出接口

- CLI：批次触发和状态查询
- API：给后台看板读取任务状态
