# 数据字典（VOC 数据产品版）

## 1. 分层约定

- `cfg_`：配置表
- `dim_`：维表
- `ods_`：原始采集层
- `dwd_`：标准明细层
- `dws_`：汇总指标层
- `ads_`：应用层

## 2. 关键表与字段

### cfg_voc_search_playbook

| 字段 | 类型 | 说明 |
|---|---|---|
| country_code | string | 国家编码 |
| product_line_code | string | 品线编码 |
| platform_code | string | 平台编码 |
| priority_level | string | P1/P2/P3 |
| station_query | string | 站内搜索语句 |
| community_bool_query | string | 布尔检索语句 |

### ods_voc_content_raw

| 字段 | 类型 | 说明 |
|---|---|---|
| source_content_id | string | 源内容 ID |
| url_raw | string | 原始 URL |
| body_raw | text | 原始正文 |
| publish_time_raw | datetime | 原始发布时间 |
| raw_json | json | 源回包 |
| snapshot_time | datetime | 采集时间 |

### dwd_voc_content_std

| 字段 | 类型 | 说明 |
|---|---|---|
| voc_content_sk | string | 标准主键 |
| content_type_std | string | 标准内容类型 |
| body_std | text | 清洗正文 |
| lang_code | string | 语言编码 |
| like_cnt | int | 点赞数 |
| reply_cnt | int | 评论数 |
| platform_code | string | 平台编码 |
| country_code | string | 国家编码 |

### dws_voc_country_line_day

| 字段 | 类型 | 说明 |
|---|---|---|
| dt | date | 日期 |
| country_code | string | 国家 |
| product_line_code | string | 品线 |
| platform_code | string | 平台 |
| content_cnt | int | 内容数 |
| negative_cnt | int | 负向内容数 |
| positive_cnt | int | 正向内容数 |

## 3. 数据质量规则

- 主键不可为空
- URL 不能为空
- 时间字段必须标准化为 UTC 或明确时区
- HTML 标签不得进入 Excel 交付层
