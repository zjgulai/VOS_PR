## 如何重跑并入主簿（integrate）

1. 确认已安装依赖（如 `openpyxl`、`pandas`）。
2. 在 **`专题2：VOC分析`** 项目根打开终端。
3. 执行目标脚本，例如：

```bash
python "外部平台锁定/B_过程与资产/08_生成脚本/09_升级国家深挖框架/integrate_india_formal_into_master.py"
```

4. 输出写入路径由 `config/project_paths.DELIVERY_DIR` 等决定，一般为 `C_结果与交付/07_综合交付/` 下对应 xlsx。

## 目录习惯用法

- **只读结论**：优先 **C**，不要深入 B 的底稿目录。
- **复用工作流**：看 **B** 的 `09_升级国家深挖框架` 与 `08_生成脚本`。
- **对齐标准与输入**：看 **A**。

## 常见问题

**Q：为什么有两个 `09_升级国家深挖框架`？**  
**A：** 一层在 `B_过程与资产/09_`（方法论与各国资产，体积大）；另一层在 `B_过程与资产/08_生成脚本/09_`（仅脚本）。代码里分别对应 `FRAMEWORK_DIR` 与 `SCRIPTS_FRAMEWORK_DIR`。

**Q：旧链接失效怎么办？**  
**A：** 以根目录 `README.md` 的「路径对照」为准；核心索引已批量更新为带 `A_`/`B_`/`C_` 前缀的路径。
