## 一、公式定义

### 1.1 最终分数公式

```
content_quality_score = min(100, base_score + risk_boost) × 100

其中：
  base_score = S×0.35 + R×0.25 + B×0.20 + T×0.10
  risk_boost = max(匹配风险词的最高权重, 0)

约束规则：
  if (互动量 < 10) and (risk_boost == 0):
      score = min(score, 44)   # 低互动无风险词，上限 Sev1
```

### 1.2 五个维度定义

#### S — 来源权威度（Source Authority，权重 35%）

> 这个来源说的话，市场和媒体会相信吗？

| 来源类型 | 代表平台 | S值 |
|---------|---------|-----|
| 监管机构 | CPSC / FDA / FTC / Health Canada | 0.95-1.00 |
| 独立测评 | Consumer Reports / Wirecutter / Stiftung Warentest | 0.90-0.92 |
| 法律风险 | ClassAction.org / TINA.org | 0.85-0.92 |
| 权威母婴媒体 | Babylist / Forbes Vetted / The Bump | 0.78-0.82 |
| 综合育儿媒体 | Parents / What to Expect | 0.72-0.78 |
| 社区平台 | Reddit | 0.60 |
| 视频平台 | YouTube | 0.55 |
| 软性媒体 | Motherly / 博客 | 0.65 |
| 社交媒体 | TikTok | 0.40 |
| 社交媒体 | Instagram | 0.38 |
| Facebook Groups | Facebook Groups | 0.45 |
| PR通稿 | GlobeNewswire / PRNewswire | 0.45 |

#### R — 传播扩散力（Reach，权重 25%）

> 这条内容在同平台里传播了多远？

```python
engagement = like_count + comment_count × 2
R = 该内容在同平台所有内容中的互动量百分位（0-1）
```

**各平台互动量参考分位（基于真实数据）：**

| 平台 | P50（中位数） | P90 |P99 |
|------|------------|-----|-----|
| Reddit | 3 赞 | 29 赞 | 200+ 赞 |
| TikTok | 32 赞 | 3,856 播放 | 20,000+ |
| YouTube | 待采集 | 待采集 | — |

#### B — 品牌相关度（Brand Proximity，权重 20%）

> 这条内容对 Momcozy 品牌的直接影响有多大？

| 条件 | B值 |
|------|-----|
| 直接提及 momcozy 或 kleanpal（品牌名） | 1.00 |
| 标题含"momcozy"或"kleanpal" | 0.90 |
| 提及 T1 直接竞品（eufy/elvie/willow/spectra/medela/frida/grownsy）| 0.85 |
| 提及核心型号词（m5/s12/wearable pump）| 0.65 |
| 提及"breast pump"（泛词，在 brand_mentions 字段中）| 0.45 |
| 标题含"breast pump"或"sterilizer" | 0.40 |
| 无明确品牌/产品关联 | 0.30 |

#### T — 时效衰减（Time Decay，权重 10%）

| 发布距今 | T值 |
|---------|-----|
| ≤ 7天 | 1.00 |
| 8-30天 | 0.90 |
| 31-90天 | 0.70 |
| > 90天 | 0.50 |

#### K — 风险词提升（Risk Boost，加法项，最大 +0.50）

> 出现特定风险词时，直接拉高分数，不受其他维度天花板限制

| 风险词 / 短语 | K提升值 | 风险类型 |
|-------------|--------|---------|
| "paying creators to lie" | +0.50 | 声誉/FTC合规 |
| "class action" | +0.45 | 法律 |
| "lawsuit" / "recall" / "fake review" | +0.40 | 法律/产品安全 |
| "false advertising" / "microplastic" / "coating peeling" | +0.38 | 监管/产品安全 |
| "injury" / "hazard" | +0.35 | 产品安全 |
| "don't buy" / "scam" | +0.25-0.28 | 声誉 |
| "terrible output" / "hate" | +0.10-0.15 | 用户体验（弱信号）|

## 二、告警阈值（与 PR 方案原文 Sev 体系对齐）

| 等级 | 分数区间 | 响应时间 | 触发条件示例 |
|------|---------|---------|------------|
| **Sev4_危急** | ≥ 75分 | 15分钟确认 | "Momcozy paying creators to lie"（100分）|

| **Sev0_观察** | < 25分 | 周报汇总 | 边缘内容 / 无关联内容 |

## 三、过滤规则（D用途之一）

进入周报的最低门槛：

```python
# 进入 PR Intelligence 周报的条件（满足其一即可）
def should_include(score, risk_boost, source_type):
    if score >= 40:          return True   # Sev2+ 全部纳入
    if risk_boost >= 0.35:   return True   # 有重大风险词即使分数低
    if source_type in ["cpsc","fda","ftc","classaction"]: return True  # 监管源全部纳入
    return False

# 直接丢弃的条件
def should_discard(score, platform, like_count, brand_mentions):
    if score < 10:           return True   # 极低分
    if platform == "tiktok" and like_count < 1000 and not brand_mentions:
        return True  # TikTok 低互动无品牌提及内容
    return False
```

## 四、实现方式（DuckDB SQL）

```sql
-- 在 social_posts / pr_articles 表上计算权重分数
-- （S值通过 JOIN dim_info_source_quality 获取，K值用 CASE WHEN）

CREATE OR REPLACE VIEW v_content_quality_scores AS
WITH source_authority AS (
    SELECT
        'reddit'           AS platform_code, 0.60 AS s_score UNION ALL
        SELECT 'tiktok',    0.40 UNION ALL
        SELECT 'youtube',   0.55 UNION ALL
        SELECT 'instagram', 0.38 UNION ALL
        SELECT 'cpsc',      1.00 UNION ALL
        SELECT 'fda',       1.00 UNION ALL
        SELECT 'classaction',0.92 UNION ALL
        SELECT 'babylist',  0.82 UNION ALL
        SELECT 'wirecutter',0.90
),
scored AS (
    SELECT
        p.post_id,
        p.platform_code,
        p.title,
        p.like_count,
        p.comment_count,
        p.brand_mentions,
        p.published_at,
        -- S
        COALESCE(sa.s_score, 0.40) AS S,
        -- R（百分位近似，用对数代理）
        LEAST(1.0, LN(1 + p.like_count + p.comment_count * 2) /
              LN(1 + CASE p.platform_code
                       WHEN 'reddit' THEN 390  -- P90*3
                       WHEN 'tiktok' THEN 11568
                       ELSE 300 END)) AS R,
        -- B
        CASE
            WHEN list_contains(p.brand_mentions, 'momcozy') OR
                 list_contains(p.brand_mentions, 'kleanpal') THEN 1.00
            WHEN lower(p.title) LIKE '%momcozy%' OR
                 lower(p.title) LIKE '%kleanpal%' THEN 0.90
            WHEN list_contains(p.brand_mentions, 'eufy') OR
                 list_contains(p.brand_mentions, 'elvie') OR
                 list_contains(p.brand_mentions, 'willow') OR
                 list_contains(p.brand_mentions, 'spectra') THEN 0.85
            WHEN list_contains(p.brand_mentions, 'wearable pump') OR
                 list_contains(p.brand_mentions, 'm5') THEN 0.65
            WHEN list_contains(p.brand_mentions, 'breast pump') THEN 0.45
            WHEN lower(p.title) LIKE '%breast pump%' THEN 0.40
            ELSE 0.30
        END AS B,
        -- T（简化为固定值，实际按日期计算）
        0.85 AS T,
        -- K（风险词提升）
        CASE
            WHEN lower(p.title) LIKE '%paying creators to lie%' THEN 0.50
            WHEN lower(p.title) LIKE '%class action%' OR
                 lower(p.title) LIKE '%lawsuit%' THEN 0.40
            WHEN lower(p.title) LIKE '%recall%' OR
                 lower(p.title) LIKE '%fake review%' THEN 0.40
            WHEN lower(p.title) LIKE '%don%t buy%' OR
                 lower(p.title) LIKE '%scam%' THEN 0.25
            ELSE 0.0
        END AS K
    FROM social_posts p
    LEFT JOIN source_authority sa ON p.platform_code = sa.platform_code
)
SELECT
    post_id, platform_code, title, like_count, brand_mentions,
    S, R, B, T, K,
    ROUND(LEAST(1.0, S*0.35 + R*0.25 + B*0.20 + T*0.10 + K) * 100, 1)
        AS quality_score,
    CASE
        WHEN LEAST(1.0, S*0.35 + R*0.25 + B*0.20 + T*0.10 + K) >= 0.75 THEN 'Sev4_危急'
        WHEN LEAST(1.0, S*0.35 + R*0.25 + B*0.20 + T*0.10 + K) >= 0.60 THEN 'Sev3_严重'
        WHEN LEAST(1.0, S*0.35 + R*0.25 + B*0.20 + T*0.10 + K) >= 0.40 THEN 'Sev2_升级'
        WHEN LEAST(1.0, S*0.35 + R*0.25 + B*0.20 + T*0.10 + K) >= 0.25 THEN 'Sev1_关注'
        ELSE 'Sev0_观察'
    END AS sev_level
FROM scored;
```
