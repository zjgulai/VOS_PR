# 登录墙与反爬解决方案

## 1. 标准处理策略

1. 识别失败类型（login_wall / anti_crawler / dynamic_render）
2. 进入对应处理队列
3. 执行自动重试或半自动流程
4. 写回结果与证据

## 2. 场景化方案

| 场景 | 方案 | 产出 |
|---|---|---|
| 登录墙 | 合规登录 + 手工 SOP + 结果录入模板 | 登录记录 + 回补结果 |
| 反爬 | 代理池、限速、请求指纹治理 | 重试成功率提升 |
| 评论树缺失 | 深链定位 + 评论分页补抓 | 评论明细表 |
| JS 渲染 | 浏览器态抓取 + DOM 解析 | 结构化正文 |

## 3. SOP 最小模板

- 任务编号
- 目标 URL
- 失败类型
- 处理人
- 处理步骤
- 结果状态
- 证据截图/备注
