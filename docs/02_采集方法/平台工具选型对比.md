# 平台工具选型对比

## 1. 选型维度

- 覆盖能力（静态/动态/登录态）
- 稳定性与可维护性
- 合规与风控能力
- 成本与接入复杂度

## 2. 工具对比

| 工具 | 优势 | 短板 | 适用场景 |
|---|---|---|---|
| Firecrawl | 快速提取结构化内容 | 深登录态支持有限 | 公开页面与结构化抽取 |
| BrightData | 代理与反爬能力强 | 成本较高 | 登录墙、强风控平台 |
| Apify | 生态成熟、Actor 丰富 | 需治理任务分散 | 电商、社媒批量任务 |
| 自建脚本 | 可控性高 | 运维压力大 | 稳定场景、定制规则 |

## 3. 推荐组合

- 默认：自建脚本 + Firecrawl
- 风控场景：补充 BrightData
- 电商深抓：补充 Apify/专项 API
