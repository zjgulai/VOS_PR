# 方法论总览

## 1. 方法链路

```text
输入边界 -> 数据清洗 -> 画像基座 -> 媒体库 -> 行级组装
-> 重点国家 -> 深挖 -> 入口打法 -> 关键词 -> P1 作业单
-> 落表方案 -> 综合交付 -> QA
```

## 2. 采集方法原则

- 先可用后完美：优先保证高价值国家与 P1 组合可用
- 自动优先：能自动就不手工，手工动作必须沉淀 SOP
- 证据优先：所有结论可追溯至 URL 与原始文本
- 质量优先：采集成功不等于可交付，需经过 QA

## 3. 方法分层

- 战略层：国家、品线、平台优先级
- 执行层：任务、脚本、批次、失败处理
- 交付层：标准表、指标、可视化、决策建议
